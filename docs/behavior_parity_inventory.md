# Inventario de revisión por declaración pública

Referencia de comportamiento: C++ 5.3.5.14, ver [informe inicial](behavior_parity_audit.md) y [correcciones verificadas](behavior_parity_fixes.md).

Este inventario cubre 748 declaraciones exportadas fuera de internal y tests. Cada fila registra la inspección del cuerpo/delegación y la correspondencia C++ que pudo localizarse. ESTÁTICA significa inspección sin oracle runtime individual; no afirma equivalencia. CORREGIDA identifica un contrato o dependencia cubierto por las regresiones que resolvieron R01–R23. CAMINO COMPARTIDO remite al dispatcher/stream inspeccionado. EXTENSIÓN, ADAPTADOR, PARCIAL y EMULACIÓN declaran límites explícitos del cotejo; un nombre de familia no afirma igualdad de implementación. Las referencias a métodos C++ pueden apuntar a una declaración, macro o llamada; la evidencia de implementación de cada hallazgo está en el informe.

El test AST TestBehaviorReviewInventoryCoversExportedDeclarations verifica el alcance del inventario, sin contar los métodos promovidos por embedding dos veces.
